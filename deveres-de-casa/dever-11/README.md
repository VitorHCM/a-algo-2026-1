# DEVER DE CASA: Djikstra

## Instrucoes da Atividade

### 1. Descricao do Problema (GRAFO)

Considere um grafo direcionado com os vertices (0, 1, 2, 3, 4) e as seguintes arestas com seus respectivos pesos configurados:

  > (0,1)=4, (0,2)=1, (2,1)=2, (2,4)=5, (3,4)=1

### 2. O que o aluno deve fazer

Aplique o Algoritmo de Dijksra partindo do no 0 e encontre o caminho minimo ate o no 4.
Entregue os seguintes itens:

- A execucao passo a passo (tabela mostrando atualizacoes das distancias de cada no visitado).

- O caminho final percorrido e o custo minimo total destacado.
