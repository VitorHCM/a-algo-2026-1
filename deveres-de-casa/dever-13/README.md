# Algoritimo KNN - Aplicação Médica.

Aplicar K-NN ao Breast Cancer Wisconsin e classificar como benigno ou
maligno. Faça a atividade utilizando Python.

### I N S T R U Ç Õ E S

1. Carregar com sklearn.datasets.load_breast_cancer()
2. Separar treino e teste (80 / 20)
3. Normalizar os dados
4. Treinar K-NN com K = 1, 3 e 5
5. Testar Euclidiana e Manhattan
6. Comparar acurácia entre as combinações
